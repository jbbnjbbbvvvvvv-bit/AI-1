# 验证范围

公开包含 35 项自动测试：24 项经验维护事务测试与 11 项暖色纹样几何测试。全部使用合成或临时数据，不依赖未公开项目资料。

几何测试覆盖已知框料宽度、不同材料亮度、裁切开放边界、小闭环保护、矩形角点、圆弧 bulge、锐角保持、背景排除、DXF 原生回读与重复轮廓签名。事务测试覆盖分级、主题路由、去重、候选转正门禁、路径范围、默认预演、失败记录、代码测试门禁、锁、并发与回滚。

验证命令为 `python -X utf8 -B -m unittest discover -s tests -v`。当前发布准备在 Python 3.13 / Windows 中验证；其他 Python/平台需自行跑测试。可用时还运行 skill-creator quick_validate；其缺失应明确记录，不报已通过。

既有工作流还来自未公开 CAD 案例的只读验证与用户纠正。真实 CAD 数据、输入哈希、照片、定位坐标和现场尺寸未纳入公开包，因此这些历史案例不能由本仓库独立复现。匿名案例说明方法，不宣称实测或施工验收。

未覆盖真实斜拍的单应变换、镜头畸变、强阴影、遮挡后构造及全部几何类型。cad_checks 的类型/布局限制见 [scripts.md](scripts.md)。结构审计、轮廓数量、截图相似和合成测试都不能单独证明装饰语义、历史真实性或绝对配准精度。
