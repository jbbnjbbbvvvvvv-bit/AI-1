# 几何与证据验收

## 检查与证据

| 项目 | 证据 |
| --- | --- |
| 文件/版本 | 输入完整路径、SHA-256、角色、单位、回读及审计结果；输出另存；前后输入哈希一致。 |
| 原生实体 | Model、块定义和展开计数分列，按类型/图层统计；图片实体与可编辑构件分别计数。 |
| 拓扑 | 重复、短线、开放端、自交、闭合与控制点检查，注明容差和方法；区分样条采样点与独立短线实体。 |
| 纹样保护 | 单独核对四瓣/卷草/心形孔/菱形组合、挂点和破损线，局部放大同尺度叠图；缺失的关键细节应先恢复。 |
| 变换 | 读输出 INSERT 矩阵，验证等比；逆变换源顶点/控制点和曲线等参数采样；报告最大误差与单位。 |
| 非目标保护 | 比较原模型句柄、块定义及子块、层属性、尺寸/注记、原布局和视口；差异须对应授权范围。 |
| 布局 | 验证实际视口、冻结层、打印比例和 Model 共用关系，查看回读 PNG 或 PDF。 |

## 图像误差统计

使用相同像素网格、Y 轴映射、原点、灰度阈值和渲染设置。输出双向最近线距离、P95、最大值、漏线/新增线范围及高误差位置。区域分母要清楚；只取距 CAD 若干像素内的原线会掩盖漏线，不能称为完整召回率。矩形区域混入其他类别会产生大误差，应按原图语义掩膜细分或明确列出干扰。噪声减少在同一纹理样区衡量，不能把建筑细节减少算作成功。

不把一个成功的孔口、数量一致、图像 IoU 或截图相似扩大为整幅几何通过。若某项没运行、类型不支持、原资料不足或只作抽样，报告该项范围和未验证状态。

## 失败模式与禁止事项

| 失败 | 约束与验收 |
| --- | --- |
| 自动描边碎线、锯齿 | 分构件识别和拟合，回读实体/曲线检查及局部叠图。 |
| 框料双边界变单线 | 保护成对轮廓及可见宽度，用横断面或格孔核验。 |
| 重构时改造雕花 | 原纹样/可靠母版作依据，核对主瓣、卷端、孔口及接口。 |
| 只平滑、视觉噪声仍多 | 独立材质层，报告固定样区降噪与构件保留。 |
| 全图清稿丢饰纹 | 保护区域分算法，关键特征缺失判该区域不合格。 |
| 无来源三重门框 | 保留原框，移植仅作用于确认替换区，新框须有来源。 |
| 非等比拉伸 | 验证 INSERT 的绝对 X/Y 比例和矩阵轴长/正交性。 |
| 纹理总包络用于安装尺度 | 主体与纹理单独包络，按原开口实轮廓检查。 |
| Model 与布局不一致 | 实际视口回读，排查嵌套冻结、重复图形和样式。 |
| 一处移植改动其他成果 | 全部原对象及块快照差分，保护组逐实体比较。 |
| 只凭截图宣布通过 | DXF 回读、几何比对及阶段状态并列报告。 |
| 类型参考误称历史实测复原 | 图签/注记/报告维持来源证据状态；像素及 CAD 浮点精度不能充当实物精度。 |

脚本的相同定义检测与逆变换检验仅覆盖其列明类型，复杂实体、局部共线、自交和装饰语义需按任务补充。开放端点允许保留原石缝、褶尾和未知连接，但应逐区定位，不批量补齐。
