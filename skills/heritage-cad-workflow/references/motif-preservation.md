# 装饰纹样保形

以当前对象原图或已核验的原生母版为依据，先识别中心节点、四向主瓣/卷草、端部回勾、叶形、心形空隙、外围过渡框及连接部位。保护区覆盖双边界和有意义的短枝；噪声阈值不能覆盖这些保护对象。原图存在左右差异时分别处理，镜像须经图源或当次方案授权。

保形平滑只消除无意义的小锯齿和微折，不改变识别特征、孔口数量和主纹拓扑。连续曲线保留足够控制点；真实圆弧才用 ARC。处理后按同坐标、同尺度叠图，并比较节点、端卷、孔口、轮廓和与框料交接。

已完成的精细 CAD 纹样直接复用 SPLINE、ARC、LINE 和原生块，不再次栅格化或整体描边。移植中以同一等比变换作用于全部母版；安装中心与左右镜像残差分别量取。八角过渡框可能同时存在于源、目标两侧，先核实实体归属和重复关系，不能未经确认整条删除跨越横档的闭合多段线。局部替换方法见 [dxf-transfer.md](dxf-transfer.md)。

P1 的破损木窗与帘布、P2 的四瓣与密集菱形、P3 的卷草和八角框是不同保护类型；不得互用纹样补造。来源不明或遮挡构造列待核。验收采用 [quality-audit.md](quality-audit.md)，案例状态见 [n03-cases.md](n03-cases.md)。
