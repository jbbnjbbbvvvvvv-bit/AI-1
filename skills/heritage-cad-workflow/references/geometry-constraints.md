# 建筑几何约束



| 类别 | 优先方法 | 保护与验收 |
| --- | --- | --- |
| 拱券和建筑主轮廓 | 在可追踪轮廓上拟合 ARC 或 SPLINE，记录拟合误差，分缝单独提取 | 只有通过圆弧检验才用 ARC。保留拱脚、非标准拱形、错台及可辨石缝。 |
| 规则框料、横档、竖梃 | 基于原图建立水平/竖向图结构，归并同一构件的接点，对源支持的宽度和模数约束 | 有宽度构件保留双边界；横线在梃边正确终止，不能穿越构件。 |
| 菱形、方格、回纹 | 在各区域分别估计方向、间距、宽度；保留格孔拓扑，裁接到真实框边 | 独立检测单元数量和边格。各侧不同模数可以保留；复制 BLOCK 前核对确属同组。 |
| 花芯、卷草、雕花 | 保护连通成分、孔口和主卷端，局部保形平滑，优先复用原样条 | 识别特征和有意义的短枝保留；高精度完成的纹样避免再次整体描边。 |
| 破损窗、布帘、裂边 | 区分完整构件直边与破损/褶皱自由曲线，轻度平滑 | 保留真实缺口、挂点和主要褶线；遮挡处归属不明的几何标待核。 |
| 材质与地面 | 较强降噪，按区域保留代表性长边和主要基准，独立图层 | 记录清理清单及固定样区的噪声变化。只让曲线变圆不能证明噪声减少。 |

## 线稿到 CAD

先生成分区净化稿，再按构件类别建立可编辑的 CAD。已有可靠 CAD 可直接保留其规范几何；灰度掩膜清稿与 CAD 构件调整分别记录。规则边界采用 LINE/LWPOLYLINE，核实圆形和圆弧采用 CIRCLE/ARC，自由曲线采用 SPLINE。全图自动描边结果可供识别，不能直接作为最终几何规范成果。

主结构、构造、装饰/纹理按图层设置线宽。常用示例为 0.35、约 0.20、0.13 mm，属于打印线宽；DXF 的二级线宽可使用支持的 0.18/0.25 mm 枚举并说明。正式预览按请求使用白底黑线。
