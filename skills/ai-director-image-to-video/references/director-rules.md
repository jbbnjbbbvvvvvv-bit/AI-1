# Director Rules Reference

## 1. 镜头选择矩阵

| 场景特征 | 首选镜头 | 谨慎 | 禁忌 |
|---|---|---|---|
| 巨型古建筑 | Slow Push-In / Static | Truck | 大幅 Orbit |
| 巨型鸟类近景 | Slow Push-In / slight tracking | Crane | 快速追拍 |
| 小人物+巨物 | Static / Slow Push-In | slight Pan | 快速推拉 |
| 瀑布峡谷 | Drone Glide / Push-In | Crane Down | 快速旋转 |
| 大量书法纹理 | Static / micro Push-In | slight Truck | 大幅视差 |
| 巨型灵体 | Static / slow reveal | Push-In | 大幅人物式动作 |

## 2. 运动幅度规则

### 人物
小人物：呼吸、视线、轻微抬头、衣摆。
中景人物：可增加手腕、半步、轻微转身。
近景人物：可增加表情、眼神、发丝和细微姿态变化。

### 鸟类
大型鸟类的动作必须体现重量。3秒镜头优先一次翼下压或滑翔，不推荐两次以上明显扑翼。

### 建筑
建筑主体默认完全固定。建筑的“动态感”应来自摄影机视差、光线反射、旗帜、门帘、雾气等附属元素。

### 灵体
轮廓越巨大，整体动作越少。内部介质可持续流动。

## 3. 风场规则

一个镜头默认只有一个主风场。定义：方向、速度、稳定性、受影响对象。

禁止人物头发向左、衣带向右、羽毛向上、云向另一方向高速漂移等互相冲突运动。

## 4. 物理因果链

优先使用：

主运动 → 局部空气变化 → 次级材质响应 → 环境微响应

例如：

凤凰翼下压 → 翼尖飞羽延迟弯曲 → 尾羽形成惯性拖曳 → 邻近薄云产生极轻微卷动。

## 5. 复杂画面降级策略

当画面包含复杂建筑 + 人物 + 动物 + 云雾 + 文字时：

1. 锁建筑和文字。
2. 一级主体只保留一个。
3. 摄影机改为静机或慢推进。
4. 环境只保留一个低频运动。
5. 光影保持固定。
6. 加强 temporal consistency 负面约束。

## 6. 3秒镜头导演规则

3秒不是完整动作表演，而是长镜头中的一个可信切片。

推荐节奏：

- 0–0.5s：建立
- 0.5–2.3s：主动作
- 2.3–3.0s：惯性延续

禁止最后0.2秒突然停住。

## 7. Kling 提示词优先级

提示词前部：

结构锁定 → 主体 → 动作 → 摄影机 → 次级响应 → 环境

提示词后部：

光影 → 情绪 → cinematic / photorealistic → 技术标签 → negative constraints

不要用大量风格词覆盖动作控制。
