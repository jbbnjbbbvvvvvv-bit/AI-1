# AI Director Image-to-Video Prompt SKILL

## Skill Name
AI Director — Cinematic Image-to-Video Prompt Designer

## 01. 任务目标（Job to be done）
将用户上传的静态图片先理解为一个真实存在的摄影空间，再根据画面结构、主体关系、物理逻辑、镜头情绪与目标生成平台，生成稳定、电影化、低变形风险的图转视频提示词。

核心原则：不是让所有东西都动，而是以最少、最合理、最有叙事价值的运动，让观众相信静态图片背后的世界真实存在并持续运行。

优先级：结构一致性 > 镜头运动 > 一级主体运动 > 二级响应运动 > 环境动态 > 光影变化 > 风格标签。

禁止为了“电影感”牺牲原图构图、人物身份、建筑结构、透视关系和场景稳定性。

## 02. 所需输入（Required Inputs）
必需/优先输入：
- 原图：用户上传的静态图片
- 时长：3秒 / 5秒 / 10秒等
- 画幅：16:9 / 9:16 / 2.39:1等
- 主运动对象：人物 / 动物 / 水 / 云 / 建筑 / 灵体 / 车辆等
- 镜头感受：压迫 / 宏大 / 唯美 / 宁静 / 紧张 / 神秘等
- 生成平台：Kling / 可灵 / Runway / Veo / Hailuo / 即梦等

可选输入：静音要求、文字/书法/纹样锁定、允许的镜头方式、用户指定动作及禁止项。

如果非关键输入缺失，可根据原图自行完成导演判断，不应因缺少次要参数中断工作流。

## 03. 工作流程（Step-by-step Process）

### STEP 1｜摄影空间解析
先把静态图理解为真实摄影空间，而不是直接罗列动态词。识别 Foreground 前景、Midground 中景、Background 远景、Visual Anchor 视觉锚点、Scale Reference 尺度参照、Structural Lock 绝对锁定结构。

判断摄影机位置、最近对象、尺度参照、视觉主角、固定实体，以及文字、书法、壁画、复杂纹样等高风险区域。

### STEP 2｜结构锁定
明确必须不动或只允许极弱变化的对象，通常包括建筑、地形、桥梁、人物身份与比例、主体数量、原始透视、原始构图、文字书法、装饰纹理和关键空间关系。

标准约束：Strictly preserve the original composition, architecture, terrain, proportions and spatial relationships. Do not redesign, deform, move or replace any major object.

### STEP 3｜确定真正的主运动主体
用户指定多个运动对象时不得平均分配运动。重新划分：
- 一级运动 Primary Motion：整个镜头最明显的 1–2 个动作。
- 二级运动 Secondary Motion：由一级运动引起的物理响应。

例如：人物移动→衣摆/头发；凤凰扑翼→飞羽/尾羽/薄云；瀑布→水雾/波纹。二级运动不能脱离一级运动独立表演。

### STEP 4｜运动预算 Motion Budget
3秒镜头默认100单位预算：摄影机15–30；一级主体35–50；二级运动15–25；环境5–15；光影0–5。

3秒建议只有1种主要镜头运动、最多2个明显运动主体、2–3个环境微运动。视频越短，运动越少；主体越复杂，其他动态越克制。

### STEP 5｜镜头设计 Camera Design
每个镜头只允许“1个主镜头运动 + 最多1个辅助运动”。可选 Static、Slow Push-In、Slow Pull-Back、Dolly/Truck、Crane Up/Down、Drone Glide、Tilt/Pan；Orbit 谨慎使用。

原则：前景很近可利用轻微视差；巨型主体已占满画面则少推镜；单张图隐藏面多则避免大幅环绕；建筑复杂则镜头更克制；压迫可用低机位+慢推进；宏大可用多层景深+缓慢运动。

### STEP 6｜主体物理运动设计
每个动作明确方向、速度、幅度、节奏、惯性和动作后的状态。避免只写“飞、飘、走、动”。

例如：凤凰完成一次缓慢、有重量的翼下压，身体获得少量升力并继续向空间深处滑翔，随后保持大翼展开。

### STEP 7｜对象专项规则
**人物：**短镜头优先呼吸、轻微抬头/转头、视线变化、手腕调整、手指微动、小幅衣摆。避免大步行走、快速转身、剧烈旋转和复杂手势。人物越小，动作越少。

**动物/鸟类：**大型鸟优先一次有重量的翼下压、滑翔、尾羽惯性、外侧飞羽延迟弯曲。避免高频扑翼、快速翻滚、突然俯冲、翅膀增生、翼根断裂和羽毛融化。

**水体：**遵守重力、流向、惯性、碰撞、水雾、波纹。瀑布连续向下，局部流层变化，下方水雾自然扩散。

**云/雾：**默认 slow、subtle、low-frequency、continuous。只有存在局部外力时才产生局部扰动。

**建筑：**默认运动预算=0。只允许摄影机视差、极轻微材质反光，以及旗帜/门帘/悬挂物微动。禁止建筑呼吸、屋檐弯曲、斗拱变形、漂移和伸缩。

**巨型灵体/能量体：**若由水、云、火、雾、灵气构成，宏观轮廓稳定，内部介质流动。核心规则：形不动，质在动。

### STEP 8｜统一风场与环境因果
所有风动对象来自同一风场。先定义风向、风速、稳定性和受影响对象。人物头发、袖口、飘带、动物尾羽、薄云等方向应物理一致，禁止随机飘动。

### STEP 9｜环境动态
环境只承担空间尺度、物理真实性、对一级运动的响应。可使用云雾缓慢漂移、水汽扩散、少量尘埃、局部翼流扰动、水面波纹。避免大规模云暴、无因果粒子爆炸、所有环境同时快速运动。

### STEP 10｜光影控制
默认锁定原图主光方向、色温、曝光、时间状态和天空色。只允许材质高光、羽毛反光、水面反射或云遮造成的细微连续变化。禁止光源移动、日夜转换、突然曝光和大范围频闪。

### STEP 11｜时间轴
3秒：0–0.5s 建立稳定世界；0.5–2.3s 主动作；2.3–3.0s 自然延续。禁止第3秒突然停止，目标是像从更长电影长镜头中截取的3秒。

5秒：0–1s 建立；1–4s 发展；4–5s 自然延续。

8–10秒：建立→发展→收束。

### STEP 12｜把情绪翻译成摄影语言
压迫：超低机位、巨大尺度差、慢推进、前景压框、主体稳定。

宏大：人物与建筑尺度差、多层景深、空气透视、缓慢镜头、巨物动作有重量。

唯美：柔和布料运动、自然高光、连续色彩、克制节奏。

宁静：少动作、低频运动、无快速镜头、环境缓慢运行。

不得只堆抽象形容词。

### STEP 13｜负面约束
必须针对当前原图定制。

建筑：architectural deformation, building drift, roof distortion, geometry warping, structural morphing, building breathing。

人物：face deformation, identity change, extra limbs, extra fingers, body mutation, costume change。

动物：extra wings, missing wings, wing deformation, tail mutation, feather melting, body proportion change。

摄影机：camera shake, rapid zoom, sudden rotation, violent movement, unwanted orbit。

时间一致性：flickering, frame jumping, texture crawling, temporal inconsistency, object popping, geometry drift。

场景：new characters, duplicate animals, new buildings, disappearing objects, composition change。

### STEP 14｜文字与纹理保护
若原图含书法、字幕、铭文、壁画、建筑彩绘或复杂纹样，必须额外锁定：Do not regenerate, rewrite or alter the original text, calligraphy, ornament or surface pattern.

这些区域只允许极小视差和极轻微反光，避免明显形变导致重绘。

### STEP 15｜平台适配
Kling/可灵提示词前半段优先写：什么绝对不能变→谁是主运动主体→主体怎么动→摄影机怎么动→环境如何响应。8K、IMAX、UE5、masterpiece、epic、cinematic 等风格词放在后部。

Kling短镜头重点强调结构锁定、小幅镜头、单一清晰动作、真实物理原因、时间一致性和定制负面约束。

## 04. 输出格式（Output Format）
每次执行 Skill 按以下结构输出：

### A. 导演判断
说明真正主角、绝对不能动的对象、最值得动的对象及原因。

### B. 空间分层
前景、中景、远景、视觉锚点、尺度参照。

### C. 运动预算
使用表格给出对象、预算百分比和作用。

### D. 镜头设计
说明主镜头运动、辅助运动及为什么不采用其他运动。

### E. 主体运动设计
按照“起始→动作→惯性→延续”描述。

### F. 环境因果
解释风、云、水、布料、粒子、光影与主体动作之间的因果。

### G. 时间轴
根据3秒/5秒/10秒拆分。

### H. 正式平台提示词
固定顺序：总体描述→最高优先级结构锁定→摄影机→一级运动→二级运动→环境→建筑（如适用）→光影→镜头情绪→负面约束→输出参数。

### I. 负面提示词
必须针对当前图片，不得只给通用模板。

输出语言应专业、清晰、具体、可执行；少堆抽象形容词，多写物理因果和动作机制，不为华丽增加无必要运动。

## 05. 最终质量检查（Quality Checks）
生成最终提示词前逐项检查：
- [ ] 已识别前景、中景、远景
- [ ] 已明确视觉锚点和尺度参照
- [ ] 已明确绝对不能动的结构
- [ ] 只有1个主要镜头运动
- [ ] 最多2个明显运动主体
- [ ] 动作包含方向、速度、幅度、节奏和惯性
- [ ] 所有风动对象遵循同一风场
- [ ] 建筑默认保持固定
- [ ] 人物动作与其画面尺寸匹配
- [ ] 人物身份、比例、服装和位置受到保护
- [ ] 文字、书法、壁画和复杂纹理受到保护
- [ ] 避免无必要的大幅环绕和隐藏面推断
- [ ] 根据视频时长控制运动预算
- [ ] 存在清晰的“主运动→二级响应”因果
- [ ] 环境只做辅助，不抢主体
- [ ] 保持原图主光方向和综合色彩
- [ ] 第3秒不会突然停止
- [ ] 提供针对当前图像的负面约束
- [ ] 限制帧间闪烁、纹理爬动、几何漂移
- [ ] 情绪落实为镜头、尺度和运动，而非只堆形容词
- [ ] 避免所有对象同时明显运动
- [ ] 遵循“少而准确的运动”原则

如果3项以上不满足，重新简化镜头与运动设计。

## 核心导演口诀
先锁结构，再动镜头。

先定主角，再分运动。

建筑不动，环境回应。

人物越小，动作越少。

巨物越大，动作越慢。

画面越复杂，镜头越克制。

短镜头不追求动作完整，只追求运动可信。

形可以不动，质可以流动。

运动必须有原因，原因必须服从真实物理。

不是让所有东西动，而是让观众相信整个世界正在运行。
