# Golden Examples

这些案例不是固定提示词，而是用于验证 AI Director Skill 的导演决策是否正确。

## Case 01｜悬空宫殿 + 峡谷 + 瀑布 + 仙鹤

### 输入特征
- 3秒
- 东方玄幻
- 巨型古建筑
- 峡谷与瀑布
- 飞行仙鹤
- 宏大 / 宁静

### 正确导演判断
视觉锚点是悬空宫殿，宫殿必须绝对稳定。一级运动优先仙鹤或瀑布之一，另一个降为持续背景运动。摄影机采用缓慢推进或轻微无人机漂移。

### 错误倾向
- 宫殿漂浮或移动
- 仙鹤高频扇翅
- 云海高速翻滚
- 摄影机同时推进、旋转、下降
- 瀑布和云雾抢过主体

### 合格标准
观众首先感受到空间尺度，其次才注意到生命运动。

## Case 02｜书法巨幕 + 古建筑 + 小人物

### 输入特征
- 3秒
- 大量书法文字
- 古建筑复杂纹样
- 小比例人物
- 唯美 / 宁静 / 压迫

### 正确导演判断
风险评级 HIGH。书法和建筑全部锁定。人物只做轻微抬头、呼吸或衣带响应。摄影机静机或极慢推进。

### 错误倾向
- 书法文字被重新生成
- 巨幕大幅飘动导致文字扭曲
- 建筑屋檐弯曲
- 小人物大步行走
- 大幅环绕产生隐藏面幻觉

### 合格标准
文字保持可识别，建筑结构稳定，人物运动极少但有生命感。

## Case 03｜巨型水灵体 + 宫殿 + 小人物

### 输入特征
- 巨型透明/水质人物轮廓
- 小人物尺度参照
- 宫殿横向展开
- 神秘 / 宏大 / 宁静

### 正确导演判断
使用“形不动，质在动”。巨型灵体的宏观轮廓不执行人体动作，内部水丝、粒子和表面高光持续缓慢流动。小人物只允许衣摆和发丝微动。

### 错误倾向
- 灵体走路
- 灵体快速转头
- 灵体轮廓重新生成
- 宫殿被水流拖动
- 粒子爆炸

### 合格标准
巨物看起来有生命，但其存在感来自内部介质运动而不是大幅肢体动作。

## Case 04｜凤凰掠过云上宫殿

### 输入特征
- 凤凰占据画面主要面积
- 羽毛结构复杂
- 云海与建筑
- 小人物作为尺度参照
- 宏大 / 唯美

### 正确导演判断
凤凰是唯一一级主体。3秒内完成一次缓慢、有重量的翼下压或保持展开滑翔。尾羽与飞羽承担二级惯性。建筑完全锁定，云只做翼流附近的局部微响应。

### 错误倾向
- 连续高速扇翅
- 多出翅膀
- 尾羽变成液体
- 凤凰突然转向镜头
- 云层整体爆发式运动

### 合格标准
首先可信，其次壮观。凤凰动作具有重量和空气阻力。

---

## Golden Rule
如果模型为了“更震撼”增加了更多主体运动、更多镜头运动或更多环境特效，应判定为偏离 Skill。

优秀结果通常比模型的第一直觉更克制。
